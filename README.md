# Cyber Threat Analyzer

A cybersecurity tool that analyzes QR codes, URLs, and suspicious links for phishing threats.

## Features

- QR Code scanning
- URL extraction
- Suspicious URL detection
- DNS reputation checking
- VirusTotal threat intelligence integration

## Tech Stack

- Python
- OpenCV
- Streamlit
- VirusTotal API
- Cyber Threat Intelligence

VirusTotal API integration requires API key configuration through Streamlit Secrets.
