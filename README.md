# 🛡️ ABS VIGIL

## Advanced Behavioral Shield

ABS VIGIL is an intelligent cybersecurity platform designed to analyze QR codes, URLs, and suspicious links to identify potential phishing attacks and online security threats.

The platform combines URL analysis, QR code scanning, and threat intelligence to help users detect malicious content before interacting with it.

---

## 🚀 Features

### 📱 QR Code Security Scanner
- Scan QR codes and extract embedded links
- Identify hidden URLs inside QR codes
- Analyze QR-based threats

### 🔍 URL Threat Analysis
- Analyze suspicious URLs
- Detect potentially malicious patterns
- Identify phishing risks and unsafe links

### 🌐 DNS & Domain Reputation Checking
- Perform DNS reputation checks
- Analyze domain information
- Identify suspicious domain behavior

### 🛡️ VirusTotal Threat Intelligence Integration
- Connect with VirusTotal API
- Perform multi-engine security analysis
- Retrieve threat reputation insights

## ⚙️ Configuration

ABS VIGIL uses the VirusTotal API for threat intelligence analysis.

To configure:

1. Create a VirusTotal API key
2. Add the API key securely using Streamlit Secrets
3. Run the application
